### About This Fork

WurmModLoader is a respectful fork that aims to modernize the original codebase while preserving full backward compatibility with existing mods. This project would not exist without the pioneering work of ago1024 and the contributors who created and maintained WurmServerModLauncher.

**Modernization Goals:**
- Upgrade to Java 17+ with modern language features
- Replace Maven with Gradle build system
- Implement annotation-driven event system and registries
- Provide enhanced documentation and developer tools
- Maintain 100% compatibility with legacy mods
